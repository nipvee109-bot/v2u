# V2U Phase 49 — UX hardening test report

Internal report. Persona and all data used here are **SYNTHETIC** test fixtures, not real user data.

## Persona

ปวช.3 · เทคโนโลยีธุรกิจดิจิทัล · target วิศวกรรมคอมพิวเตอร์ · 30 นาที/วัน (generic CE route; no verified admission data exists).

## Journey tested (real Chromium, production build)

Fresh install → onboarding → set starting point on เส้นทาง → Home "วันนี้ควรทำอะไร" → choose time → เริ่มขั้นต่อไป → resource confirmation → Study Room (timer) → เสร็จสิ้นการเรียน → summary + unclear topic → quiz (3 questions) + confidence → save → Home / เส้นทาง / roadmap week → review comes due → ReviewRoom (recall → open notes → rate → save) → Home moves on → backup export → wipe local data → import → everything identical.

## Screens

Home, onboarding dialog, เรียน, หลักสูตร (expanded), เส้นทาง (stages + checklist), ทบทวน, ฉัน (readiness, GPAX, admission summary), ตั้งค่า (import/export), legacy deep links (/dashboard, /roadmap, /goals, /planner, /progress, /analytics, /weekly-review, /resources, /not-understood, /search, /subjects/math, /lessons/:id), resource confirmation dialog, Study Room, post-study dialog (3 steps), ReviewRoom.

## Viewports

320 · 375 · 390 · 430 · 768 · 1024 · 1280 px — 25 screens/states each (175 audits). Each audit checks: no horizontal overflow (page and element level), no unnamed buttons/links, no unlabeled form fields, exactly 5 visible primary navigation items, no console errors. Result after fixes: **0 issues**.

Keyboard: skip link is the first Tab stop and moves focus to `#main-content`; the Home primary CTA is reachable by Tab with a visible focus ring; onboarding, resource confirmation and post-study dialogs close with Escape.

PWA: `manifest.webmanifest` (short_name V2U, display standalone, start_url /) and a Workbox service worker are generated by the build.

## Issues found and fixed (each has a regression test in `scripts/test-phase-49.js`)

| # | Issue | Fix |
|---|---|---|
| 1 | New installs were seeded with demo history (completed planner sessions, an in-progress lesson, an overdue review). Onboarding never appeared and Home told a new student to review a topic they had never studied. | Fresh install, reset and old-backup import start clean; demo generators removed. |
| 2 | Seeded study-resource library contained placeholder/unverifiable links (`sample1`, `example.com`, …) shown in "ยืนยันแหล่งเรียน". | Removed; no seeded links. |
| 3 | Onboarding weekly load (e.g. 12 ชม./สัปดาห์) did not change V2U's daily time, so plans used a different time than chosen. | Onboarding sets the nearest daily time option. |
| 4 | "เริ่มเรียนคาบแรกเลยทันที" skipped resource confirmation and started its own lesson pick (could differ from Home). | Starts the shared next step through confirmation. |
| 5 | Resource confirmation said "ยังไม่มีสื่อการเรียน" and "2 ชม." right after Home recommended a resource and 30 นาที. | Shows V2U's recommendation (with where to find it, link not checked) and today's minutes. |
| 6 | Study Room timer target was the lesson's legacy 120 min; empty viewer gave no guidance. | Uses the session's planned minutes; shows the recommendation. |
| 7 | Post-study next action froze at dialog open; after typing an unclear topic, advice said "ทบทวน" while "เรียนบทถัดไป" stayed selected. | Follows the recommendation until the student picks. |
| 8 | "เรียนบทถัดไป" opened a lesson chosen by list order — a second decision path. | "ไปขั้นต่อไป" returns to the shared next step. |
| 9 | "คิวทบทวน" opened the planner. | Opens ทบทวน. |
| 10 | ReviewRoom header text was invisible (global `.card` white background overrode the dark gradient). | Header no longer uses `.card`. |
| 11 | Header bell always showed a red dot and did nothing. | Links to ทบทวน; dot only when something is due; label states the count. |
| 12 | Note fields in Study Room and post-study dialog had no programmatic labels. | `label`/`htmlFor` + ids. |
| 13 | Post-study and resource-confirmation dialogs could not be closed with Escape. | Escape closes them. |
| 14 | Jargon and an unsupported claim ("+50% Retention", "Neural Pathway", "Active Recall Challenge", English "Mastery/Spaced Repetition" labels). | Plain Thai; claim removed. |
| 15 | Home gave no hint that the starting point was still the default ("สาขาอื่น"). | Small link to เส้นทาง until a profile is set. |

Consistency matrix (automated): Home next step === roadmap today === first item of this week after fresh state, unfinished study, overdue review, weak skill, completed lesson, changed time, changed profile, changed GPAX, changed admission checklist.

## Deferred (intentionally)

- One trackable lesson covers several curriculum lessons, so completing it advances all of them at once (e.g. 3 math lessons). Needs per-curriculum-lesson progress — a data-model change for a later phase.
- Existing users' saved data may still contain old demo history or placeholder links; it is user data and is not deleted automatically.
- Export filename still starts with `nextstep-backup-` (pinned by an earlier test); rename in Phase 50.
- Post-study step 3 still shows "ระดับ x/4" and the label "ก้าวถัดไปที่แนะนำ (Recommended Next Action)" (pinned by the Phase 40 test); legacy pages (Dashboard, Analytics, Planner) still contain English/technical terms.
- Roadmap weekly capacity assumes 5 study days per week (labelled "ประมาณ").
- Not covered: real iOS/Android devices and PWA install, screen-reader testing, real students. Chromium only.
- No verified admission or resource links: blocked on official sources (unchanged).
